# SMD-GOV-001 — No Programme Without SMD Accountability

Every programme, technology, infrastructure, and neural-network system shall be linked to an accountable organization, a lifecycle phase, a merit-evidence record, and a democratic review mechanism.

## Key Elements

- Mandatory four-link metadata on every P / T / I / N node.
- Validation in CI and audit.
- Non-compliance blocks release.

## Traceability

- Linked governance rule: `SMD-GOV-001`
- Lifecycle model: `LC01-LC14`
- Evidence target: `08_EVIDENCE_AND_MERIT/`
