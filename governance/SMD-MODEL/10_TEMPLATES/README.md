# 10_TEMPLATES — Reusable SMD Templates

Reusable templates for SMD nodes, merit-evidence records, democratic-review records, programme accountability, and traceability matrices.

- `TEMPLATE-SMD-Node.md` — generic node template.
- `TEMPLATE-Merit-Evidence-Record.yaml` — MER schema instance.
- `TEMPLATE-Democratic-Review-Record.yaml` — DRR schema instance.
- `TEMPLATE-Programme-SMD-Accountability.md` — programme accountability template.
- `TEMPLATE-SMD-Traceability-Matrix.yaml` — traceability matrix schema.
